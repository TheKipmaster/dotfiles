## Zettelkasten
The folder at ~/Zettelkasten contains my growing knowledge base under the zettelkasten system. Whenever you teach me a concept that is not present in it, you should remind me to make a note and relate it back to other notes in my knowledge bank so it keeps expanding. When doing so, suggest which Indexes are appropriate and which notes already exist relating to the new concept, but let me write Atomic Notes myself.

### Writing to the Zettelkasten
- **`/Templates` is the source of truth.** Notes that don't match their template's format are outdated — flag them with an 'outated-template' tag rather than following their example.
- **Do not write to `/Atomic Notes`.** Those are for my own thoughts in my own words. Writing there defeats the purpose.
- **"Write a learning prompt"** means: use the `Learning Prompt.md` template and save to `/Learning/`. When writing one, first ask me for what to put in the prior knowledge section. Then fill in Teaching Objectives and Learning Goals collaboratively — Teaching Objectives are your agenda items for the session, Learning Goals are my exit criteria (what I should be able to do or explain afterward). After that, you should be able to come up with the Prerequisites, and finally the Context section captures the key quote or insight from the conversation that motivated the note.
- When suggesting related notes to link to, check what already exists in the vault before proposing links.
- When filling in the `created` timestamp, run `date` to get the actual current time rather than fabricating one. Format: `YYYY-MM-DDTHH:MM:SS`.

### Study Sessions
When I tell you to fetch a Learning Prompt note to start a study session: read the full note, briefly restate the Teaching Objectives so we're aligned on scope, then work through them in order using the Socratic approach. Close the session by deriving active recall questions from my Learning Goals so I can self-test retention.
